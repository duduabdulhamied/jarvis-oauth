Jarvis Personal

Jarvis Personal adalah aplikasi pribadi milik Abdul Hamied. Integrasi Google Drive dipakai oleh pemilik untuk melihat daftar file dan membuka file miliknya melalui server pribadi ARP Mint.

Integrasi ini tidak ditawarkan sebagai layanan publik dan tidak menjual atau membagikan data Google kepada pihak lain.
