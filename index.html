Jarvis Personal

Saya memiliki aplikasi pribadi yang saya beri nama Jarvis. Aplikasi ini saya buat khusus untuk membantu kebutuhan saya sendiri.

Tujuan integrasi Google Drive

Saya menyimpan seluruh data pribadi yang saya kelola di Google Drive. Saat halaman ini dibuat, akun Google saya menggunakan paket penyimpanan berkapasitas 5 TB.

Saya menghubungkan Jarvis dengan Google Drive agar penyimpanan, pencarian, backup, dan pengelolaan file dapat saya lakukan dengan lebih mudah dari satu aplikasi pribadi.

Ruang lingkup akses

Saya memberikan akses penuh kepada Jarvis untuk melihat, membuat, mengunggah, memperbarui, memindahkan, mengunduh, dan menghapus file di Google Drive saya. Akses ini diperlukan karena Google Drive menjadi penyimpanan utama data yang saya kelola melalui Jarvis.

Penggunaan terbatas

Jarvis benar-benar saya buat dan saya gunakan sendiri. Aplikasi ini tidak menerima pendaftaran pengguna, tidak disediakan sebagai layanan untuk umum, dan hanya dapat dibuka melalui akun serta perangkat yang saya izinkan. Data Google Drive saya tidak dijual, disewakan, atau dibagikan kepada pihak lain.
