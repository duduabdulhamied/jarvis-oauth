Jarvis Personal

Kebijakan Privasi

Dokumen ini menjelaskan cara aplikasi pribadi saya, Jarvis, terhubung dengan akun Google Drive milik saya.

Terakhir diperbarui pada 23 September 2026.

Tentang Jarvis dan Google Drive

Jarvis adalah aplikasi pribadi yang saya buat dan benar-benar hanya saya gunakan sendiri. Aplikasi ini tidak menerima pendaftaran pengguna dan tidak disediakan sebagai layanan untuk umum.

Saya menyimpan seluruh data pribadi yang saya kelola di Google Drive. Saat kebijakan ini dibuat, akun Google saya menggunakan paket penyimpanan berkapasitas 5 TB. Saya menghubungkan Jarvis dengan Google Drive agar penyimpanan, backup, pencarian, dan pengelolaan file dapat dilakukan dari satu aplikasi pribadi.

Integrasi ini berjalan pada server pribadi ARP Mint dan hanya dapat digunakan setelah masuk ke Jarvis dari perangkat yang sudah saya izinkan.

Tujuan penggunaan akses

Jarvis menggunakan Google Drive sebagai penyimpanan utama untuk data dan file yang saya kelola. Integrasi ini digunakan untuk melihat, mencari, membuka, mengunduh, menyimpan, membuat, memperbarui, memindahkan, dan menghapus file melalui Jarvis.

Akses penuh Google Drive

Akses penuh diperlukan agar fungsi penyimpanan, backup, dan pengelolaan file dapat berjalan. Saya sendiri yang memberikan otorisasi dan menggunakan fungsi tersebut melalui Jarvis.

Data yang dapat diakses

Dengan izin penuh Google Drive, Jarvis secara teknis dapat mengakses informasi akun dan kuota penyimpanan, membaca metadata dan isi file, serta membuat, mengunggah, mengunduh, memperbarui, memindahkan, dan menghapus file di Google Drive saya.

Akses tersebut hanya digunakan untuk perintah dan fitur yang saya jalankan sendiri di Jarvis. Saya tetap menjadi pemilik dan pengendali data maupun akun Google Drive yang terhubung.

Cara data diproses

Permintaan ke Google Drive dikirim oleh server pribadi ARP Mint setelah saya masuk ke Jarvis. Data diproses hanya sejauh yang diperlukan untuk menjalankan fungsi yang saya pilih, termasuk penelusuran, penyimpanan, backup, dan pengelolaan file.

Jarvis tidak menjual, menyewakan, atau memberikan data Google Drive saya kepada pihak lain. Data tersebut digunakan hanya untuk kepentingan pribadi saya.

Keamanan kredensial

Refresh token dan kredensial OAuth disimpan dalam bentuk terenkripsi pada server ARP Mint. Access token hanya disimpan sementara di memori selama layanan berjalan. Browser dan perangkat yang saya gunakan tidak menerima client secret, refresh token, atau access token.

Pencabutan akses

Saya dapat menghentikan integrasi kapan saja dengan mencabut akses Jarvis Personal melalui pengaturan Akun Google dan menghapus kredensial terenkripsi dari server.
