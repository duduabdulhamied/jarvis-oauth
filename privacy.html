Kebijakan Privasi Jarvis Personal

Terakhir diperbarui: 23 September 2026.

Tujuan

Jarvis Personal memakai Google Drive API agar pemilik dapat melihat daftar folder dan file, mencari nama file, melihat metadata dasar, serta membuka file pada layanan Google Drive.

Data yang diakses

Scope Google Drive baca saja secara teknis mengizinkan aplikasi melihat dan mengunduh file. Implementasi Jarvis saat ini meminta identitas akun, informasi kuota, dan metadata file seperti nama, tipe, ukuran, waktu perubahan, status bersama/favorit, serta tautan tampilan. Jarvis tidak menyediakan fitur upload, edit, pindah, berbagi, atau hapus.

Penyimpanan dan keamanan

Refresh token dan OAuth client disimpan sebagai systemd encrypted credential pada server pribadi ARP Mint. Access token hanya dicache sementara di memori proses. Browser dan perangkat pengguna tidak menerima client secret, refresh token, atau access token. Daftar isi Drive tidak disimpan sebagai cache offline oleh Jarvis.

Berbagi dan penjualan

Data Google tidak dijual, disewakan, atau dibagikan kepada pihak lain oleh Jarvis Personal. File yang dipilih dibuka langsung pada domain resmi Google.

Retensi dan pencabutan

Kredensial dipertahankan selama integrasi digunakan. Pemilik dapat mencabut akses melalui halaman koneksi akun Google dan menghapus credential terenkripsi dari server.
