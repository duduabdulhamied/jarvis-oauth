Jarvis Personal

Kebijakan Privasi

Dokumen ini menjelaskan cara aplikasi pribadi saya, Jarvis, terhubung dengan akun Google Drive milik saya.

Terakhir diperbarui pada 23 September 2026.

Tentang Jarvis dan Google Drive

Jarvis adalah aplikasi pribadi yang saya buat dan gunakan untuk kebutuhan sendiri. Saya menghubungkan Jarvis dengan Google Drive supaya penyimpanan dan pengelolaan file pribadi dapat dilakukan dengan lebih mudah dari satu aplikasi.

Integrasi ini berjalan pada server pribadi ARP Mint dan hanya dapat digunakan setelah masuk ke Jarvis dari perangkat yang sudah saya izinkan.

Fungsi yang tersedia saat ini

Jarvis dapat menampilkan folder dan file, mencari file berdasarkan nama, serta membuka file melalui layanan resmi Google Drive.

Akses masih baca saja

Penyimpanan dan backup dari Jarvis ke Google Drive belum diaktifkan. Fitur tersebut akan saya siapkan secara terpisah.

Data yang dapat diakses

Jarvis memakai izin Google Drive baca saja. Izin tersebut secara teknis memungkinkan aplikasi melihat dan mengunduh file. Dalam penggunaan saya saat ini, Jarvis hanya meminta informasi akun dan kuota penyimpanan, serta metadata file seperti nama, jenis, ukuran, waktu perubahan, status berbagi, status favorit, dan tautan untuk membuka file.

Jarvis tidak menyediakan fungsi untuk mengunggah, mengubah, memindahkan, membagikan, atau menghapus file di Google Drive.

Cara data diproses

Permintaan ke Google Drive dikirim oleh server pribadi ARP Mint. Informasi yang diperlukan kemudian ditampilkan pada halaman Google Drive di Jarvis. Saat saya memilih sebuah file, Jarvis membukanya melalui tautan resmi Google Drive.

Daftar file tidak disimpan sebagai salinan offline oleh Jarvis. Data Google Drive juga tidak dijual, disewakan, atau diberikan kepada pihak lain.

Keamanan kredensial

Refresh token dan kredensial OAuth disimpan dalam bentuk terenkripsi pada server ARP Mint. Access token hanya disimpan sementara di memori selama layanan berjalan. Browser dan perangkat yang saya gunakan tidak menerima client secret, refresh token, atau access token.

Pencabutan akses

Saya dapat menghentikan integrasi kapan saja dengan mencabut akses Jarvis Personal melalui pengaturan Akun Google dan menghapus kredensial terenkripsi dari server.
